# How to Use Block Usage

The “Block Usage” screen is in the [PublishPress Blocks](https://publishpress.com/links/blocks) plugin. This screen allows you to search for and find any usage of blocks on your site.

In the screenshot below, this feature has found 245 instances of the “Paragraph” block used across 24 posts and pages. There are also 25 Heading blocks, 2 List blocks, 2 Quote blocks, and 27 Image blocks.

![Block Usage screren](https://docs-media.publishpress.com/publishpress-blocks/blocks-usage-22b367c6ad.webp)

You can use this feature to scan as many post types as you want.

![Block Usage scan post type](https://docs-media.publishpress.com/publishpress-blocks/block-scan-post-types-fe6f4d82cc.webp)

In the sidebar of the “Block Usage” screen, you will be able to drill down and see more details on each location. In this next screenshot, I found all the uses of a “Table” block on my site. With one click, I’m able to see all the posts that contain this block.

![Blocks found with the Block Usage screen](https://docs-media.publishpress.com/publishpress-blocks/table-block-usage-b8e956d11b.webp)

If you click on any post title, you can drill down to see the blocks in that post, including the block you’re looking for.

![Searching for blocks with the Block Usage screen](https://docs-media.publishpress.com/publishpress-blocks/block-usage-table-a3ddae7abe.webp)
