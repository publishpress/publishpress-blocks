# Search Bar Block

Table of Contents

- [How to add a Search Bar block](#h-how-to-add-a-publishpress-search-bar-block)
- [Settings for the Search Bar block](#h-settings-for-the-publishpress-search-bar-block)

The PublishPress “Search Bar” block is available in the [PublishPress Blocks](https://publishpress.com/links/blocks) plugin. This allows you to add a very customizable search form into Gutenberg. You can change the colors, icons, width and text of your search bar.

## How to add a Search Bar block [#](#h-how-to-add-a-publishpress-search-bar-block)

You can create a search textbox on by clicking the “Search Bar – PublishPress”button in the [PublishPress Blocks](https://publishpress.com/links/blocks) category.

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-175330-c6d6fa611c.webp)

## Settings for the Search Bar block [#](#h-settings-for-the-publishpress-search-bar-block)

You can adjust the PublishPress Search Bar settings on the right panel.

- **Styles:** there are 2 predefined styles: Default and Classic
- **Search Bar State**  Full width: On/Off Width
- **Search Icon Settings**  Search icon on the right: On/Off Search icon

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-175415-ca1ef0b020.webp)

- **Search Input Settings**  Search placeholder Input Color: Background and Text color

![](https://docs-media.publishpress.com/publishpress-blocks/search-input-settings-0687069db0.webp)

- **Search Button Settings**  Show submit button: On/Off Search button on the left: On/Off Background and Text color Border radius
- **Hover Colors:**Background, Text and Shadow color
- **Hover Shadow:**Opacity, Transition speed and Shadow (H (horizontal) offset, V (vertical) offset, blur, spread)

![](https://docs-media.publishpress.com/publishpress-blocks/search-button-settings-1-42a1d5ce67.webp)
