# Social Links Block

You can share your social media profiles very easily by using the “Social Links” block in the [PublishPress Blocks](https://publishpress.com/links/blocks) plugin. This block allows you to add links to your company / organization / personal profile on all the major social networks.

## How to add a Social Links block [#](#h-how-to-add-a-publishpress-social-links-block)

You can add this block by clicking the “Social Links – PublishPress” button in the [PublishPress Blocks](https://publishpress.com/links/blocks) category.

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-175652-8ab2e82f3d.webp)

This next image shows the Social Links block inside the Gutenberg editor:

![](https://docs-media.publishpress.com/publishpress-blocks/social-links-2933e0ea90.webp)

## How to add new links to your Social Links block [#](#h-how-to-add-new-links-to-your-publishpress-social-links-block)

- After you have created a PublishPress Social Links blocks, click on one of the icons shown below:

![](https://docs-media.publishpress.com/publishpress-blocks/add-social-media-link-44b9292336.webp)

- Enter the full URL to your social media profile.
- In the right sidebar, choose icon for this social network.

![](https://docs-media.publishpress.com/publishpress-blocks/choose-icon-1-8e4f81daff.webp)

- Repeat this process for more social networks:

![](https://docs-media.publishpress.com/publishpress-blocks/choose-twitter-1-f7dce42229.webp)

- If you want to add more social profiles, click the + icon above your **Social Links** block:

![](https://docs-media.publishpress.com/publishpress-blocks/add-social-link-aac5940e6f.webp)

## Settings for the Social Links block [#](#h-settings-for-the-publishpress-social-links-block)

You can use the ready-made icon or upload your own icon, and adjust some more options from the right panel.

- **Preset Icons:**you can upload your custom icon
- **Preset Icon Color**
- **Icons settings**  Icon size, space

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-175733-9d3cf30960.webp)

## Default settings for the Social Links blocks [#](#h-default-settings-for-the-publishpress-social-links-blocks)

You can set default options for every PublishPress Social Links block added to your site. This is possible with the [PublishPress Blocks default configuration](https://publishpress.com/knowledge-base/default-blocks-config/) feature and it allows you to create a consistent look-and-feel for all your social links.

- Go to **Blocks** in your WordPress admin menu, then **PublishPress Blocks**.

- Click **Social Links** settings icon.

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-175839-fd8b81d067.webp)

- Adjust the default settings and save.

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-175854-85eb831811.webp)
