# How to Use Block Permissions

By using the [PublishPress Blocks](https://publishpress.com/links/blocks) plugin, you can control which user roles can add which Gutenberg blocks while editing content. For example, if you want to prevent “Author” users from adding “Table” blocks, you can block them from doing that with this feature.

You can decide which blockswill be available to each user role.

To get started, go to “Blocks” admin menu, then “Block Permissions”. In the top-left corner, you can choose the user role you want to edit.

You can enable or disable blocks in Gutenberg by clicking on the toggle buttons. When you’re finished, click the “Save Block Permissions” button to update the user role.

![Block Permissions screen](https://docs-media.publishpress.com/publishpress-blocks/block-permissions-screen-be9724fb8d.webp)

Once saved, the blocks will be available (or not available) in your editor when the user creates posts.

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-133948-038b59fe23.webp)

Tip: if you want to disable or enable all the blocks at once, use “Enable or disable all blocks” toggle, taking in consideration at least one block must be enabled in order to save the configuration.

![Disable all blocks](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-134030-362eb431c4.webp)
