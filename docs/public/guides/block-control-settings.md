# Block Control Settings

You can enable or disable specific [Block Controls](https://publishpress.com/links/block-controls) per block type by going to “Blocks”, then “[Block Controls](https://publishpress.com/links/block-controls)” then visiting the “Controls” tab. Uncheck any Block Control to disable that feature for your site.

![Block Controls tab](https://docs-media.publishpress.com/publishpress-blocks/block-controls-tab-23733c0c5b.webp)

You can also enable or disable Block Controls per block type by going to “Blocks”, then “Block Controls” then visiting the “Blocks” tab.

![Block Controls enable or disable](https://docs-media.publishpress.com/publishpress-blocks/block-control-settings-0dab518145.webp)

For example, there’s the process to disable Block Controls support for Paragraph blocks.

- Search for the “Paragraph” block.
- Disable the toggle for the “Paragraph” block.
- Click “Save Blocks”.

From now, if you edit a Paragraph block, Block Controls won’t be available for this block type. The rest of blocks will still have support for Block Controls.

![](https://docs-media.publishpress.com/publishpress-blocks/disable-paragraphs-116da56a55.webp)
