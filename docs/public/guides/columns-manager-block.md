The PublishPress Columns block is available in the [PublishPress Blocks](https://publishpress.com/links/blocks) plugin. This is based on the default**Columns**block in Gutenberg. This new version of the block has many extra features including extra layout options, padding, margins and much more.

## Creating a PublishPress Columns Block [#](#h-creating-a-publishpress-columns-block)

If you want to create a block containing other blocks inside, choose “Columns – PublishPress” in the [PublishPress Blocks](https://publishpress.com/links/blocks) category.

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-135945-d20ff37642.webp)

The image below shows how the block will appear when you’re adding it to your site:

## Column Settings for the PublishPress Columns block [#](#h-column-settings-for-the-publishpress-columns-block)

In the right sidebar, you can adjust the settings of PublishPress Columns block.

- **Responsive Settings**: Choose different layouts for **Desktop**, **Tablet**, and **Mobile** displays.
- **Space between columns**: Choose how many pixels show in the gap between each column.
- **Padding**: Top, Right, Left and Bottom
- **Margin**: Top, Right, Left and Bottom

![](https://docs-media.publishpress.com/publishpress-blocks/column-settings-1-0e25d84711.webp)

## Row settings for the PublishPress Columns block [#](#h-row-settings-for-the-publishpress-columns-block)

- **Columns Wrapped**: If this is enabled, any overflowing columns will be moved to a new line.
- **Wrapper Tag**: This HTML tag will wrap each row. You can choose Div, Header, Main, …
- **Content Max Width**: You can choose either px, v or %.
- **Content Min Height**: You can choose either px, v or %.
- **Content Max Height**: You can choose either px, v or %.

![](https://docs-media.publishpress.com/publishpress-blocks/column-settings-2-678a7e132f.webp)

## Custom column width [#](#custom-column-width)

You can override the width of each column. Select a column block, then in the sidebar adjust the width.

![Custom column width](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2023-02-09-at-113118-3c695806c5.webp)

Additionally you can enable border, text alignment, padding, margin and border radius.

![Custom column width settings](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2023-02-09-at-113347-2186c0547b.webp)

## Default settings for all your PublishPress Columns blocks [#](#h-default-settings-for-all-your-publishpress-columns-blocks)

You can set default options for every PublishPress Columns block added to your site. This is possible with the [PublishPress Blocks default configuration](https://publishpress.com/knowledge-base/default-blocks-config/) feature and it allows you to create a consistent look-and-feel for all your layouts.

- Go to **Blocks** in your WordPress admin menu, then **PublishPress Blocks**.

- Click **Columns** (plural) settings icon.

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-151302-b375833fd9.webp)

- Adjust the default settings and click “Save”.

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-140453-9473dec8c7.webp)
