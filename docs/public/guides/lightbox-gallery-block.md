# Add a Lightbox Display to the Gallery Block

With [PublishPress Blocks](https://publishpress.com/links/blocks) plugin, you can show WordPress images inside a lightbox modal. This feature is not available in the normal WordPress gallery block.

[iframe: https://www.youtube.com/embed/OjQ5E5NkXlE?feature=oembed]

This feature is on [the Settings screen](https://publishpress.com/knowledge-base/configuration/) > “Images” tab in [PublishPress Blocks](https://publishpress.com/links/blocks). This will modify the default “Gallery” block in WordPress.

- **Open galleries in lightbox**: This will automatically add a lightbox display to images in the “Gallery” block.
- **Image caption:**This feature will automatically take the alt text or caption for an image and show it as captions for images in lightboxes. You can choose between display the caption below the image or over.

![](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-10-04-at-171030-df999f69e4.webp)

Add a “Gallery” block to your content:

![](https://docs-media.metaslider.com/publishpress-blocks/gallery-block-acb8c10183.webp)

Even though a “lightbox” setting isn’t visible, you will be able to click on any image in the gallery and see it in a lightbox:

!['](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2021-06-18-at-131712-cbdd270e6e.webp)

WordPress allows you to add a caption to images, through the Media Library:

![](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2021-06-18-at-131051-3534e4be8b.webp)

This caption text will appear as a caption below the lightbox image:

![](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2021-06-18-at-124956-752be5eba7.webp)

If you use long captions that can’t fit below the image, Image caption overlay will show this result:

![](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2021-06-18-at-124938-71dc3e0211.webp)
