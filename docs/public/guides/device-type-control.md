# Device Width Control

The “Device Width Control” feature is part of the [Block Controls](https://publishpress.com/links/block-controls) feature in the [PublishPress Blocks](https://publishpress.com/links/blocks) plugin. This feature allows you to show and hide blocks on specific device sizes.

You can use the “Device Width” option to set the minimum and maximum screen widths for the block to display. In the screenshot below, this block will only show if the screen width is between 720px and 1920px.
