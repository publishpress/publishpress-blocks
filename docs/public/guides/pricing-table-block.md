This feature requires the Pro version of the PublishPress Blocks plugin.

With the Pro version of the [PublishPress Blocks](https://publishpress.com/links/blocks) plugin, you can create an Pricing Table block when you need to show people the purchase or subscription options on your site. This image below is a preview of how the block will appear inside the WordPress editing screen.

![Pricing Table](https://docs-media.publishpress.com/publishpress-blocks/pricing-table-3c4180164a.webp)

*Pricing Table*

## How to create the Pricing Table block [#](#h-how-to-create-the-publishpress-pricing-table-block)

You can create a PublishPress Pricing Table block by clicking the “Pricing Table – PublishPress” button in the [PublishPress Blocks](https://publishpress.com/links/blocks) category.

![Screen Shot 2022 10 05 At 18.17.34](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-181734-e6ae4230c7.webp)

*Screen Shot 2022 10 05 At 18.17.34*

## Settings for the Pricing Table block [#](#h-settings-for-the-publishpress-pricing-table-block)

Once created, you can customize the display, spacing and colors. This from the sidebar.

![Gutenberg Pricing Table block](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2021-06-17-at-124229-9b0898e7a2.webp)

- **Heading**  **Display Heading:** enabled/disable the heading. **Heading Tag:** choose the html tag for the heading. **Border Bottom:** enabled/disable the border bottom (if enabled through Border panel). **Padding top** **Padding right** **Padding bottom** **Padding left**
- **Price**  **Display Price:** enabled/disable the price. **Price Tag:** choose the html tag for the price. **Border Bottom:** enabled/disable the border bottom (if enabled through Border panel). **Padding top** **Padding right** **Padding bottom** **Padding left**
- **Features**  **Padding top** **Padding right** **Padding bottom** **Padding left**
- **Border**  **Border radius** **Border style:** choose between solid, dotted, dashed, double, groove, ridge, inset and outset.
- **Colors**  **Heading Background** **Price Background** **Features Background**

## Edit content for the Pricing Table block [#](#h-edit-content-for-the-publishpress-pricing-table-block)

You can change the “Plan Heading” like you do with regular text, including formatting options for color and style.

![Gutenberg Pricing Table block](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2021-06-17-at-125957-e5f53a7f2a.webp)

You can change the price and periodicity like you do with regular text, including formatting options for color and style.

![Gutenberg Pricing Table block](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2021-06-17-at-130016-0ae30c0339.webp)

Customize the Features List block by typing, adding, removing and reordering. More details about the Feature List block [here](https://publishpress.com/knowledge-base/feature-list-block/).

![Gutenberg Pricing Table block](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2021-06-17-at-130129-ae51ae3326.webp)

Also you can add other block types: Heading, Paragraph, Button, PublishPress Button, Spacer, Separator and PublishPress Icon.

![Gutenberg Pricing Table block](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2021-06-17-at-130231-dbae7936c1.webp)

## Alignment [#](#h-alignment)

You can align the heading and the price through the toolbar.

![Gutenberg Pricing Table block](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2021-06-17-at-194214-aa836e9c05.webp)

The other sample elements such as buttons and features have its own alignment settings.

## Pricing Tables with the PublishPress Columns block [#](#h-creating-a-set-of-pricing-tables-with-publishpress-columns-block)

In order to create the traditional pricing tables layout, you can combine PublishPress Pricing Table blocks with a PublishPress Columns block.

![Gutenberg Columns Manager and Pricing Table block](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2021-06-17-at-141524-3cb266d585.webp)

Create a [PublishPress Columns](https://publishpress.com/knowledge-base/columns-manager-block/) block. Choose the number of columns depending the number of pricing tables you need. In our example we choose 3.

![Gutenberg Columns Manager and Pricing Table block](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2021-06-17-at-141750-84b5cae608.webp)

Choose the space between columns.

![Gutenberg Columns Manager and Pricing Table block](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2021-06-17-at-142230-dc6b007be9.webp)

Insert a PublishPress Pricing Table block for each Column.

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-182127-8b8702916c.webp)

At this point this is how it looks.

![Gutenberg Columns Manager and Pricing Table block](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2021-06-17-at-142057-636a6c28b9.webp)

As last step customize the content, colors and settings.
