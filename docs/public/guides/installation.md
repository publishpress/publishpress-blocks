# How to Use PublishPress Blocks

[PublishPress Blocks](https://publishpress.com/links/blocks) is the plugin that gives you more control over the WordPress block editor.

[PublishPress Blocks](https://publishpress.com/links/blocks) has everything you need to build professional websites with WordPress. You’ll find a wide range of tools to manage the blocks on your site. You’ll also find cusotm blocks including 24 layout options, sliders, buttons, icons, image galleries, maps, tabs, accordions, and much more.

To install the plugin, you can use the standard WordPress installer.

- Go to “Plugins” in your WordPress admin menu.
- Search for “PublishPress Blocks”.
- Click “Install Now”.

![PublishPress Blocks](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-04-at-154250-6edadef991.webp)

Alternatively, you can [download the plugin from WordPress.org](http://wordpress.org/plugins/advanced-gutenberg/) and extract the folder to the **/wp-content/plugin/** folder on your WordPress site.

- Click on **Activate**and you will see the “Blocks” menu appear in the WordPress admin menu:

![Blocks dashboard screen](https://docs-media.publishpress.com/publishpress-blocks/blocks-dashboard-1-7cb5c9c428.webp)
