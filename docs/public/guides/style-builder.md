# Create and Edit Block Styles

The Style Builder is part of the Block Styles feature. The Style Builder allows you to create custom styles for your WordPress blocks, without any coding knowledge.

The settings are divided into the following tabs. Colors, Spacing, Typography, Layout, and Border are available in the Free version of the [PublishPress Blocks](https://publishpress.com/links/blocks) plugin. Text, Headings, Links, Media, Containers, and Interactive are available in the Pro version of the plugin.

![Style Builder](https://docs-media.publishpress.com/publishpress-blocks/style-builder-2-1579ec4276.webp)

Let’s see an example of how this Style Builder works. Imagine that we’re going to create a block style that uses [the PublishPress brand colors](https://publishpress.com/brand/#publishpress-colors).

- Click “Copy” next to the “Blue message” option.
- Enter a new “Style title” and “Class name”.
- Choose an “Identification color”.

![Copy a style in the Style Builder](https://docs-media.publishpress.com/publishpress-blocks/copy-style-builder-6e046f32a2.webp)

- Enter the background and text colors to use for the block, as in this next screenshot:

![Style Builder with custom colors](https://docs-media.publishpress.com/publishpress-blocks/custom-style-builder-e10555455c.webp)

You can click on the other tabs to add more customizations. In the screenshot below, I’ve opened the “Spacing” tab and entered a “Padding” option of 20px. This is now a block style that I can apply to any block on this WordPress site.

![Style Builder padding option](https://docs-media.publishpress.com/publishpress-blocks/new-block-style-bac5f0c193.webp)

If you want to avoid the Style Builder and write your own CSS, you can do that via the “Custom CSS” tab.

![Custom CSS tab in the Style Builder](https://docs-media.publishpress.com/publishpress-blocks/style-builder-custom-css-1c9b5135cb.webp)

After saving your block style, go to edit a post and you can apply your new style to any block:

![Custom block styles](https://docs-media.publishpress.com/publishpress-blocks/publishpress-blocks-style-113019bb69.webp)
