# How to Use Reusable Blocks

When you are using [PublishPress Blocks](https://publishpress.com/links/blocks), you will find a “Reusable Blocks” screen. This feature allows you to create blocks that can be used multiple times across your WordPress site. When you update the block once, it will then be updated across all the posts where it is used.

![](https://docs-media.metaslider.com/publishpress-blocks/reusable-blocks-1-5e6c18e9f5.webp)

- On this screen, click the “Add New Resuable Block” button.
- You can now create and save new a block, as in this screenshot below.

![New reusable block](https://docs-media.metaslider.com/publishpress-blocks/create-reusable-block-a814fdd069.webp)

- Whenever you create a new post, you will now be able to search for and add your reusable block.

![Reusable block](https://docs-media.metaslider.com/publishpress-blocks/select-resuable-blocks-7cc53feb04.webp)
