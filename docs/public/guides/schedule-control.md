The “Schedule Control” feature is part of the [Block Controls](https://publishpress.com/links/block-controls) feature in the [PublishPress Blocks](https://publishpress.com/links/blocks) plugin. This feature allows you to control when a specific Gutenberg block will start and stop showing. You choose the dates, days of the week, and times that your block will show.

## Schedule a block between selected dates [#](#h-schedule-a-block-between-the-selected-dates)

If you want to show a block to show, look for the “Schedule” option under “Blocks Controls” as show in this screenshot.

![Block Control Schedule](https://docs-media.publishpress.com/publishpress-blocks/block-control-schedule-65b915fb77.webp)

There are multiple options available in this feature:

- **Start showing**: Select a date to start showing the block.
- **Stop showing**: Select a date to stop showing the block.
- **Recurring**: This will appear after you have selected two dates. Enable this feature to show the block between the selected dates every year.
- **On these days**: If you want to show the block in specific days of the week, check the days here.
- **Between these times**: If you want to show the block in a time range hours, select the hours here.
- **Timezone (Pro version)**: You can select a timezone different to the site settings.
- **Add Another Schedule**: It’s possible to add multiple schedule for one block.

## Schedule a block from a starting date [#](#h-schedule-a-block-from-a-starting-date)

If you want to show a block forever (starting from a specific date), follow these steps:

- Go to the “[Block Controls](https://publishpress.com/links/block-controls)” panel.
- Enable the “Schedule” setting.
- Select a date for “Start showing”.
- Leave “Stop showing” as “Never”.

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2023-01-05-at-91605-a6295971c9.webp)

## Schedule a block until a selected date [#](#h-schedule-a-block-until-a-selected-date)

If you want to show a block until reaching a selected date, follow these steps:

- Go to the “Block Controls” panel in the right sidebar.
- Enable the “Schedule” setting.
- Leave “Start showing” as “Now”.
- Select a “Stop showing” date.

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2023-01-05-at-91708-2dcb5ced16.webp)
