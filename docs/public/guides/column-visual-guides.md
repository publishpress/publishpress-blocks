# Columns visual guides

Table of Contents

- [How to use the Columns visual guide](#h-how-to-use-the-columns-visual-guide)
- [Settings for the Columns visual guide](#h-settings-for-the-columns-visual-guide)

The “Columns visual guide” feature in the [PublishPress Blocks](https://publishpress.com/links/blocks) plugin makes it easier to see what is happening with your layouts.

## How to use the Columns visual guide [#](#h-how-to-use-the-columns-visual-guide)

To see the “Columns visual guide” feature in action, choose a [PublishPress Columns](https://publishpress.com/knowledge-base/columns-manager-block/) block:

![Add PublishPress Columns block](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-10-05-at-190547-fd0df04e80.webp)

*Add PublishPress Columns block*

Choose a layout option:

![](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-10-05-at-190636-bebc605f0e.webp)

Add content to your layout, and you will see a dotted line around the outside of each column. This is the “Columns Visual Guide”:

![Dotted Line Guide](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-10-05-at-190939-3e1d82ca62.webp)

*Dotted Line Guide*

These guidelines can be particularly useful as your layouts become more complex. This next image is an example of one “[Columns Manager](https://publishpress.com/links/columns-manager)” block inside another “[Columns Manager](https://publishpress.com/links/columns-manager)” block. In this image, the guidelines are very helpful for seeing your layout:

![Dotted Line Guide 2](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-10-05-at-191129-8f1b8e1949.webp)

*Dotted Line Guide 2*

## Settings for the Columns visual guide [#](#h-settings-for-the-columns-visual-guide)

You can choose to enable or disable the visual guide for your whole site, or individual posts / pages.

Inside every post or page, you can click the [PublishPress Blocks](https://publishpress.com/links/blocks) icon in the top-right corner. You can then choose one of these settings:

- [Inherit](https://publishpress.com/links/inherit) from global settings
- Enable
- Disable

![Visual Guide Settings 1](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2020-12-09-at-171613-989828a808.webp)

*Visual Guide Settings 1*

The “Global Settings” show above can be configured this way:

- Go to Blocks in your WordPress admin menu.
- Then Settings
- Enable columns visual guide
