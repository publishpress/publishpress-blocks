The Testimonial block in the [PublishPress Blocks](https://publishpress.com/links/blocks) plugin allows you to add clients testimonials to Gutenberg. You can add testimonials using columns or a slider. You can show the avatar, name, job position and description for each testimonial.

## How to add Testimonial blocks [#](#h-how-to-add-testimonial-blocks)

You can insert a Testimonial block into your content by clicking the “Testimonial – PublishPress” button in the [PublishPress Blocks](https://publishpress.com/links/blocks) category.

![](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-10-05-at-180655-04c944dc59.webp)

## Settings for the PublishPress Testimonial block [#](#h-settings-for-the-publishpress-testimonial-block)

In the right panel you can adjust the settings for the Testimonial. When the Slider view option is disable, here is the settings:

- **Columns:** Columns range in Normal view is 1-3, and in Slider view is 4-10.
- **Avatar:**Avatar size, background color, and border settings, which include color, radius and width
- **Text Colors:**  Name Color Position Color Description Color

![](https://docs-media.metaslider.com/publishpress-blocks/testimonial-settings-110088826b.webp)

When you enable**Slider view**option, some additional options for slider will be appear:

- **Number of items**
- **Items to show**
- **Items to scroll**

- **Center mode**
- **Pause on hover**
- **Auto play**
- **Autoplay speed (ms)**
- **Infinite Loop**
- **Transition speed (ms)**
- **Show dots**
- **Show arrows**
- **Arrow size**

![](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-10-05-at-180806-5308c7024a.webp)

## Change name, position and description size (Pro) [#](#anchor-support-pro)

This feature requires the Pro version of the PublishPress Blocks plugin.

This feature is available in the Pro version of PublishPress Blocks. You can change the size for the name, position and description.

![PublishPress Blocks - Testimonial](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-03-30-at-123403-249e858e03.webp)

1. Go to Content size panel
2. Set a custom font size for the name, position and description

## Change text alignment (Pro) [#](#anchor-support-pro)

This feature requires the Pro version of the PublishPress Blocks plugin.

This feature is available in the Pro version of PublishPress Blocks. You can change the text alignment through the toolbar align feature. Please note the avatar position can be changed through Avatar settings > Avatar > Avatar position.

![PublishPress Blocks - Testimonial](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-03-30-at-123535-09786720af.webp)

## Default settings for Testimonial blocks [#](#h-default-settings-for-publishpress-testimonial-blocks)

You can set default options for every PublishPress Testimonial block added to your site. This is possible with the [PublishPress Blocks default configuration](https://publishpress.com/knowledge-base/default-blocks-config/) feature and it allows you to create a consistent look-and-feel for all your testimonials.

- Go to **Blocks** in your WordPress admin menu, then **PublishPress Blocks**.

- Click **Testimonial** settings icon.

![](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-10-05-at-180907-0c4277d483.webp)
