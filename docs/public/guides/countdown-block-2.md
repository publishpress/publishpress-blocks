# Countdown Block (Pro)

Table of Contents

- [How to create the PublishPress Countdown block](#h-how-to-create-the-publishpress-countdown-block)
- [Settings for the PublishPress Countdown block](#h-settings-for-the-publishpress-countdown-block)

This feature requires the Pro version of the PublishPress Blocks plugin.

The Countdown block is available in the Pro version of the [PublishPress Blocks](https://publishpress.com/links/blocks) plugin. With this block, you can create a highly customizable countdown to an event. This image below is a preview of how the block will appear inside the WordPress editing screen.

![Countdown block](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2021-05-18-at-172857-89910d9528.webp)

## How to create the PublishPress Countdown block [#](#h-how-to-create-the-publishpress-countdown-block)

You can create a PublishPress Countdown block by clicking the “Countdown – PublishPress” button in the [PublishPress Blocks](https://publishpress.com/links/blocks) category.

![](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-10-05-at-171348-4594b5753f.webp)

The event date and timer are generated automatically based on the Date time from the sidebar.

![Countdown block](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2021-05-18-at-181509-7e1cf9dbb0.webp)

## Settings for the PublishPress Countdown block [#](#h-settings-for-the-publishpress-countdown-block)

Once created, you can adjust the date and time, timer, font size, colors, labels, format and more. This from the sidebar.

![Countdown block](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2021-05-18-at-173925-f4e54898b4.webp)

- **Date time:** choose the date and time for the event.
- **Timer Settings**  **Days and time display**: choose between “all in the same line” and “split in two lines”. **Font Size for days:**available when “Days and time display” is “split in two lines”. **Line Height for days:** available when “Days and time display” is “split in two lines”. **Font Size for hours, minutes, seconds** **Line Height for hours, minutes, seconds** **Separator:** separator between hours, minutes and seconds. Choose between colon, slash, hyphen, vertical line, empty space and none. **Time has come:** custom message to display when countdown comes to 00:00:00. **Display days label:** enabled/disable the label for days. **Days label (plural):** custom label to replace “days” word. **Day label (singular):** custom label to replace “day” word. **Display hours, minutes, seconds labels:** enabled/disable the label for hours, minutes, seconds labels. **Hours label (plural):** custom label to replace “hours” word. **Hour label (singular):** custom label to replace “hour” word. **Minutes label (plural):** custom label to replace “minutes” word. **Minute label (singular):** custom label to replace “minute” word. **Seconds label:** custom label to replace “seconds” word.
- **Event Settings**  **Image:** enabled/disable the image. **Image Width (px)** **Title:** enabled/disable the title. **Title Tag:** choose the html tag for the title. **Event Date:** enabled/disable the event date. **Event Date Tag:** choose the html tag for the event date. **Date Format:** choose the format for the date that is displayed. **Description:** enabled/disable the description. **Button:** enabled/disable the button. This button is an [PublishPress Button block](https://publishpress.com/knowledge-base/advanced-button-block/) with its own set of customizations. Select this block on the editor to access its settings.
- **Color Settings**  **Title Color** **Event Date Color** **Description Color** **Timer Color** **Background Color**
- **Padding**  **Padding top** **Padding right** **Padding bottom** **Padding left**
- **Border**  **Border radius** **Border style:** choose between solid, dotted, dashed, double, groove, ridge, inset and outset. **Border Color:** when Border style is different to “none”, this field will allow you to choose a custom color.

## Edit content for the PublishPress Countdown block [#](#h-edit-content-for-the-publishpress-countdown-block)

Click over the clock to choose a custom image.

![Countdown block](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2021-05-18-at-180035-2838908463.webp)

You can change the “Event’s title” like you do with regular headings.

![Countdown block](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2021-05-18-at-180113-d59c4ac11d.webp)

Type a custom description like you do with regular text.

![Countdown block](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2021-05-18-at-180201-eaa2ed4001.webp)

Click on the PublishPress Button to customize the text.

![Countdown block](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2021-05-18-at-180341-b63019f078.webp)

On the sidebar you can customize the button. Here you have the same settings from a regular [PublishPress Button block](https://publishpress.com/knowledge-base/advanced-button-block/).

![Countdown block](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2021-05-18-at-180535-ce27664715.webp)
