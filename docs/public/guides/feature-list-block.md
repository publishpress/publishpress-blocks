This feature requires the Pro version of the PublishPress Blocks plugin.

With the Pro version of [the PublishPress Blocks plugin](https://publishpress.com/blocks/), you can create a “Features List” block when you need to show a list of all the items available with a product or service. This image below is a preview of how the block will appear inside the WordPress editing screen.

![Gutenberg Feature List block](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2021-06-17-at-130600-61e4e6fc47.webp)

## How to create the PublishPress Features List block [#](#h-how-to-create-the-publishpress-features-list-block)

You can create a PublishPress Features List block by clicking the “Feature List – PublishPress” button in the [PublishPress Blocks](https://publishpress.com/links/blocks) category.

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-181538-a3a9c2c376.webp)

## Settings for the PublishPress Features List block [#](#h-settings-for-the-publishpress-features-list-block)

Once created, you can customize the text, icon, spacing, colors, and more. This from the sidebar.

![Gutenberg Feature List block](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2021-06-17-at-131039-a295c11a9b.webp)

- **Main Settings**  **Stripes:** enable/disable the stripes style. **Stripes Colors:** available when “Stripes” is enabled.  **Even Background** **Odd Background**
- **Feature Settings**  **Text size** **Icon size** **Line height** **Spacing between icon and text** **Paddding top** **Padding right** **Padding bottom** **Padding left**

## Edit content for the PublishPress Features List block [#](#h-edit-content-for-the-publishpress-features-list-block)

The features are handled through a nested block called Feature.

You can change the text of each feature like you do with regular text, including formatting options for color and style.

![Gutenberg Feature block](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2021-06-17-at-131608-697df216e2.webp)

To reorder a feature, click over the arrows.

![Gutenberg Feature block](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2021-06-17-at-131827-bbb83a95dc.webp)

To add a feature, click on the plus button on the left.

![Gutenberg Feature block](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2021-06-17-at-133359-2c592ab2a5.webp)

To remove a feature, click on the 3 dots menu > Remove block.

![Gutenberg Feature block](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2021-06-17-at-132006-860272cc5f.webp)

## Edit the icon and color [#](#h-edit-the-icon-and-color)

To choose the icon and color for each feature use the Icon Settings from sidebar.

![Gutenberg Feature block](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2021-06-17-at-133157-ce7c37b271.webp)

- **To display text without icon**, select the first option from List icon.
- **To display icon without text**, remove the text and select an icon from List icon.

## Stripes [#](#h-stripes)

By default the stripes are enabled in white and gray background colors. To customize this result, use the Stripes settings.

![Gutenberg Feature List block](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2021-06-17-at-134825-aeeeffa37c.webp)

## Alignment [#](#h-alignment)

You can align the features through the toolbar.
