# What Happens to Blocks if I Disable PublishPress Blocks?

If you disable the [PublishPress Blocks](https://publishpress.com/links/blocks) plugin, the blocks will revert to HTML. This means that [PublishPress Blocks](https://publishpress.com/links/blocks) is a safe option to use, because your content is not locked into our plugin forever.

Here is an example of our [Columns](https://publishpress.com/knowledge-base/columns-manager-block/) block, after the plugin was disabled.

![](https://docs-media.publishpress.com/publishpress-blocks/disable-columns-f6cead9250.webp)

If you click on the “Keep as HTML” button, you will see that the block uses normal HTML code. You can add your own CSS styles to your theme and keep on using this block.

![](https://docs-media.publishpress.com/publishpress-blocks/disable-columns-code-1-05dff3f2be.webp)
