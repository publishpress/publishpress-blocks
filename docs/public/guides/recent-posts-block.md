The “Content Display” is available in the [PublishPress Blocks](https://publishpress.com/links/blocks) plugin. This block is the best way to showcase your content in WordPress. Several views are available including Grid, List, Slider, Frontpage, Newspaper and Masonry.

Content filters include categories, tags, author, number of posts and more. You can decide which elements to display such as published date, updated date, time, authors, categories, tags, read more, excerpt and more.

![](https://docs-media.metaslider.com/publishpress-blocks/latest-posts-woocommerce-recent-products-d608160f2e.webp)

## How to add a PublishPress Content Display block [#](#h-how-to-add-a-publishpress-content-display-block)

You can create a “Content Display” block by clicking the “Content Display – PublishPress” button in the [PublishPress Blocks](https://publishpress.com/links/blocks) category.

![](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-10-05-at-170727-336c17648f.webp)

You can customize the default mountain thumbnail image by going to [the PublishPress Blocks Configuration](https://publishpress.com/knowledge-base/configuration/#h-images).

The default Content Display view is a grid, but you can change that through the toolbar:

![PublishPress Blocks Recent Posts views](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2021-04-12-at-112425-ed8b4e5a2d.webp)

## Sections order (Pro) [#](#11-toc-title)

This feature requires the Pro version of the PublishPress Blocks plugin.

Want to display the image below the title? This feature will be useful. In the Pro version of PublishPress Blocks, you can change the order of the sections such as image, title, info and text.

![PublishPress Blocks - Content Display](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-03-30-at-131404-1879840a8b.webp)

1. Go to Reorder sections > Sections order
2. Choose one of the order options:  Title, Image, Info, Text Image, Title, Text, Info Title, Image, Text, Info Title, Info, Text, Image Title, Text, Info, Image Title, Text, Image, Info

## Google font and text transform support (Pro) [#](#12-toc-title)

This feature requires the Pro version of the PublishPress Blocks plugin.

In the Pro version of PublishPress Blocks, you can choose between 1400 available Google fonts to customize the post title, info, content and read more link. You can choose a different font for each element! You can also transform the text: capitalize, uppercase or lowercase.

![PublishPress Blocks - Content Display](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-04-27-at-135206-b9c1208ba9.webp)

- **Font family**. Choose between 1400 available Google fonts
- **Font weight + Style**. (when Font family is different to “default”)
- **Text transform**. Choose between default, uppercase, lowercase and capitalize.

## Display specific posts (Pro) [#](#13-toc-title)

This feature requires the Pro version of the PublishPress Blocks plugin.

In the Pro version of PublishPress Blocks, if you want to display selected posts pages or other custom post type, use the “Display these posts only” field inside “Advanced Filters” panel.

![PublishPress Blocks - Content Display](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-06-02-at-165136-b8923f5f9e.webp)

This filter disables the other filters (Categories, Tags, etc). To enable back the regular “Filters” panel, clear “Display these posts only” selection.

## Autoplay speed (Pro) [#](#14-toc-title)

This feature requires the Pro version of the PublishPress Blocks plugin.

In the Pro version of PublishPress Blocks, when using Slider view with autoplay enabled, you can decide the speed. 1000 equals to 1 second. Look for “Slider view autoplay” panel.

![PublishPress Blocks - Content Display](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-04-27-at-143107-f10931411c.webp)

## Customize Title (Pro) [#](#15-toc-title)

This feature requires the Pro version of the PublishPress Blocks plugin.

In the Pro version of PublishPress Blocks, in addition to Google fonts, you choose the color and font size for the Title, including hover color. You can change this through the “Title” panel settings. The font size can be different for each device: desktop, tablet and mobile. Optionally you can hide the title based on the device.

![PublishPress Blocks - Content Display](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-05-18-at-110541-d569a6a693.webp)

- **Color**
- **Color (hover)**
- **Desktop**. You can choose a custom font size (px) or hide the title for big screens
- **Tablet**. You can choose a custom font size (px) or hide the title for medium screens
- **Mobile** You can choose a custom font size (px) or hide the title for small screens

## Customize Featured image (Pro) [#](#16-toc-title)

This feature requires the Pro version of the PublishPress Blocks plugin.

In the Pro version of PublishPress Blocks, you can change the width and height for the featured images through Featured image panel.

![PublishPress Blocks - Content Display](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-03-30-at-130844-fef2db81be.webp)

- **Custom image size**. Enable this in order to change image’s size
- I**mage width (px)**. Uncheck “auto” to set a custom image’s width.
- **Image height (px)**. Uncheck “auto” to set a custom image’s height.

## Customize Content (Pro) [#](#17-toc-title)

This feature requires the Pro version of the PublishPress Blocks plugin.

In the Pro version of PublishPress Blocks, in addition to Google fonts, you can customize the content color through the “Content” panel settings.

![PublishPress Blocks - Content Display](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-05-18-at-110706-db6cd2de6c.webp)

## Customize Read more link (Pro) [#](#18-toc-title)

This feature requires the Pro version of the PublishPress Blocks plugin.

In the Pro version of PublishPress Blocks, you can choose the design for the Read more link, including the Google font and hover event. You can change this through the “Read more link” panel settings.

![PublishPress Blocks - Content Display](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-03-30-at-130036-d453e0056c.webp)

- **Font family**. Choose between 1400 available Google fonts
- **Font weight + Style**. (when Font family is different to “default”)
- **Text transform**. Choose between default, uppercase, lowercase and capitalize.
- **Text decoration**. Choose between default, none, underline
- **Text decoration (hover)**. Choose between default, none, underline
- **Text color**
- **Text color (hover)**
- **Background color**
- **Background color (hover)**
- **Border style**. Choose between none, solid, dotted, dashed, double, groove, ridge, inset and outset
- **Border color**
- **Border color (hover)**
- **Border width**
- **Border radius**
- **Enable padding**  Padding top Padding right Padding bottom Padding left

## PublishPress Authors support [#](#h-publishpress-authors-support)

The Content Display block supports the [PublishPress Authors](https://publishpress.com/links/authors) plugin. This means you can filter by authors managed through this plugin and display more than one author.

![](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2021-04-12-at-120039-2cd010f632.webp)

## PublishPress Series support [#](#20-toc-title)

The Content Display block supports the [PublishPress Series](https://publishpress.com/links/series) plugin. This means you can display your series and order by series order option. If you use [PublishPress Series Pro](https://publishpress.com/links/series), custom post types are supported.

![](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-06-03-at-141009-e19f4d0d85.webp)
