# Blocks spacing

This feature is on [the Settings screen](https://publishpress.com/knowledge-base/configuration/) in [PublishPress Blocks](https://publishpress.com/links/blocks). If you enable this feature, it will add vertical spacing between your blocks on the frontend of your site.

The image on the left shows two PublishPress [Image blocks](https://publishpress.com/knowledge-base/advanced-image-block/) with the **Blocks spacing**feature disabled. The image on the right shows the same two images with the **Blocks spacing** feature enabled and set to **50 px**.
