The PublishPress Imageblock is available in the [PublishPress Blocks](https://publishpress.com/links/blocks) plugin. This block is based on the default Image block in Gutenberg. This improved version of the block has tons of extra features including focal points, overlays, custom text and more.

## How to create the PublishPress Image block [#](#articletoc_0)

You can create an PublishPress Image block by clicking the “Image – PublishPress” button in the [PublishPress Blocks](https://publishpress.com/links/blocks) category:

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-154810-f27e4d8bae.webp)

## Settings for the PublishPress Image block [#](#articletoc_0)

You can adjust key settings for the image by using the right sidebar:

- **Action on click** Open the image in a lightbox, or open a custom URL.
- **Link URL:**This will send visitor to a new URL if they click on the image.
- **Open link in new tab:**On/Off
- **Image Size:** Should the image be displayed as full width, or with a custom height and width.

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-154941-de31a2abf0.webp)

## Focal Point, Overlay and Text [#](#articletoc_0)

The focal point allows you to choose which part of the image is at the center of the block display. In this settings area, you can also control the image overlay, and any text.

- **Focal Point Picker:** Select a point to focus on, or choose horizontal/vertical position
- **Overlay opacity default**
- **Overlay opacity hover**
- **Color Settings:**  Titles color Subtitle color Overlay color
- **Text Alignment:**  Vertical alignment (Top, Center, Bottom) Horizontal alignment (Left, Center, Right)

![](https://docs-media.publishpress.com/publishpress-blocks/adv-image-hover-3ef575fc19.webp)

## Change title and subtitle tag (Pro) [#](#3-toc-title)

This feature requires the Pro version of the PublishPress Blocks plugin.

In the Pro version of the PublishPress Blocks plugin, you can change the HTML tag for the title and subtitle in order to display the content in a different size.

![PublishPress Blocks - Advanced Image](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-03-30-at-124430-dcc2f4e408.webp)

1. Go to Content tags panel
2. Choose a different HTML tag for the title and subtitle

## Default settings for all your PublishPress Image blocks [#](#4-toc-title)

You can set default options for every PublishPress Image block added to your site. This is possible with the [PublishPress Blocks default configuration](https://publishpress.com/knowledge-base/default-blocks-config/) feature and it allows you to create a consistent look-and-feel for all your images.

- Go to “Blocks” in your WordPress admin menu, then “PublishPress Blocks”.
- Click the “Image” settings icon.

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-155059-bef91caecc.webp)

- Adjust the default settings and save.

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-155125-5447ac50bd.webp)
