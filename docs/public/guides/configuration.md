This guide is an overview to the “Settings” screen inside the [PublishPress Blocks](https://publishpress.com/links/blocks) plugin.

## General [#](#h-general)

- **Enable blocks spacing.** Vertical spacing between blocks. [Click here for more details](https://publishpress.com/knowledge-base/blocks-spacing/).
- **Blocks spacing (px)**
- **Blocks icon color.** Set the color for block icons in the admin. This only applies to blocks from [PublishPress Blocks](https://publishpress.com/links/blocks). [Click here for more details](https://publishpress.com/knowledge-base/knowledge-base/blocks-icon-color/).
- **Gutenberg editor width.** Define the admin Gutenberg editor width size. [Click here for more details](https://publishpress.com/knowledge-base/editor-width/).
- **Enable columns visual guide.** Visual guide for PublishPress Blocks [Columns block](https://publishpress.com/knowledge-base/columns-manager-block/).

![General block settings](https://docs-media.metaslider.com/publishpress-blocks/general-block-settings-0d543fabbb.webp)

## Block Features [#](#1-toc-title)

- **Disable all block adding**: Prevent users in the selected role from adding new block to posts.
- **Disable the Pattern Directory**: Disable the pattern directory for users in the selected role.
- **Disable the Openverse**: Disable Openverse for users in the selected role.

![Disable block features](https://docs-media.metaslider.com/publishpress-blocks/disable-block-features-bf1b51a9cf.webp)

## Images [#](#h-images)

- **Open galleries in lightbox.** Open gallery images as a lightbox style popup. [Click here for more details](https://publishpress.com/knowledge-base/lightbox-gallery-block/).
- **Image caption.** Display caption text on images loaded as lightbox in galleries. [Click here for more details](https://publishpress.com/knowledge-base/lightbox-gallery-block/).
- **Default thumbnail.** Set the default post thumbnail to use in [Content Display blocks](https://publishpress.com/knowledge-base/recent-posts-block/) for posts without featured image.

![Images tab in block settings](https://docs-media.metaslider.com/publishpress-blocks/images-tab-settings-0e57a0ea5d.webp)

## Maps [#](#h-maps)

Go to Blocks admin menu, then click “Maps” tab.

- **Google API key.** A Google API key is required to use the [Map block](https://publishpress.com/knowledge-base/map-block/) without any warning.

![Google Maps setting](https://docs-media.metaslider.com/publishpress-blocks/google-maps-setting-871545a4e9.webp)

## reCAPTCHA [#](#h-recaptcha)

Go to Blocks admin menu, then click “reCAPTCHA” tab.

Use the Google reCAPTCHA to avoid spam in PublishPress Blocks forms. Get credentials for your domain by registering [here](https://www.google.com/recaptcha/about/) – choose ReCaptcha **V2**

- Fill in the reCAPTCHA Site and reCAPTCHA Secret Key.
- Enable the reCAPTCHA option.
- Choose your reCAPTCHA Language.
- Choose your reCAPTCHA Theme.

![Recaptcha settings](https://docs-media.metaslider.com/publishpress-blocks/recaptcha-settings-faec0b9b78.webp)

## Data Export [#](#h-data-export)

Go to Blocks admin menu, then click “Data Export” tab.

Here you can download data stored through Contact and Newsletter form blocks in CSV and JSON format.

## Settings through the Gutenberg editor [#](#7-toc-title)

You can also find **Editor width** and **Columns visual guide** settings at the top right corner of your Editor, next to the **Settings**icon. You can apply different configurations to individual posts and pages.
