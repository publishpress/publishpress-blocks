# PublishPress Blocks default configuration

This feature allows you to adjust the global settings for your blocks in [PublishPress Blocks](https://publishpress.com/links/blocks) plugin.

To change the settings, you can go to **Blocks >** **[PublishPress Blocks](https://publishpress.com/links/blocks)**

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-04-at-171732-c112aa0501.webp)

For each block, you can edit its default settings by clicking the adjacent **Settings**icon.

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-04-at-171813-dda35761f2.webp)

Note: “PublishPress Blocks” feature needs to be enabled in the [PublishPress Blocks Dashboard](https://publishpress.com/knowledge-base/blocks-dashboard/).
