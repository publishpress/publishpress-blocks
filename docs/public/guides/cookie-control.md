# Cookie Control

The “Cookie Control” feature is part of the [Block Controls](https://publishpress.com/links/block-controls) feature in the [PublishPress Blocks](https://publishpress.com/links/blocks) plugin. This feature allows you to show or hide block based on cookie values.

- **Cookie Name**: This is name of the cookie to use for this condition.
- **Condition**: This is based on the “Value” field. For example, if you choose = then the value of the cookie in the visitor’s browser must exactly match the content of the “Value” field.
- **Value**: This is the value of the cookie stored in the visitor’s browser.
- **Approach**: You can choose either “Show block when condition matches” or “Hide block when condition matches”.
