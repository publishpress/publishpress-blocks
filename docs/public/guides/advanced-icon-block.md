The Icon block is available in the [PublishPress Blocks](https://publishpress.com/links/blocks) plugin. This block allows you to add icons to WordPress content. This block uses Google’s Material Design icons. You can customize the style, size, color, link, margin, padding, background, border and more.

## How to create the PublishPress Icon block [#](#articletoc_0)

You can create an Icon block by clicking the “Icon – PublishPress” button in the [PublishPress Blocks](https://publishpress.com/links/blocks) category:

![](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-10-05-at-152823-5c05b339ec.webp)

## Settings for the PublishPress Icon block [#](#articletoc_0)

You can adjust key settings for the icons by using the right sidebar. The first option allows you to decide the number of icons in the row:

![](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-10-05-at-152919-d47a02f0ba.webp)

## Choose Your Icon [#](#h-choose-your-icon)

The key setting for this block is choosing your icon.

- Click the “Icon Selection” button.

![Icon Library](https://docs-media.metaslider.com/publishpress-blocks/icon-library-b01b452f0d.webp)

*Icon Library*

- You can now browse for icons, or use the “Search icons” feature.
- Select an icon and click “Apply” to add icon to your post.

![Icon Search](https://docs-media.metaslider.com/publishpress-blocks/icon-search-0775763e8f.webp)

*Icon Search*

In addition to choosing an icon, you can select a “Style” from this dropdown:

- Filled
- Outlined
- Rounded
- Two-Tone
- Sharp

![Icon Dropdown](https://docs-media.metaslider.com/publishpress-blocks/icon-dropdown-2c27fdd4f5.webp)

*Icon Dropdown*

After choosing your icon, you can also choose “Default” or “Stacked” in the sidebar. “Stacked” will add a border to the icon.

![Default Stacked](https://docs-media.metaslider.com/publishpress-blocks/default-stacked-62d0a34b78.webp)

*Default Stacked*

## Key settings for the PublishPress Icon blocks [#](#3-toc-title)

After you choose an icon, you will see extra settings in the right sidebar:

- Icon Size (in pixels)
- Icon Color
- Icon Background

![Icon Size Color](https://docs-media.metaslider.com/publishpress-blocks/icon-size-color-6c9d08465d.webp)

*Icon Size Color*

These border options will only appear if you choose “Stacked”:

- Border
- Border Size
- Border Radius

![Border Icon](https://docs-media.metaslider.com/publishpress-blocks/border-icon-820e20f4c3.webp)

*Border Icon*

The “Link” area allows you to add links to your icon. Add the icon to the box labelled “Paste URL or type to search”.

![Icon Link](https://docs-media.metaslider.com/publishpress-blocks/icon-link-00d57b7b86.webp)

*Icon Link*

In the “Padding” and “Margin” areas you can choose the padding and margin for your icons, using px, em or vh.

![Padding Margin](https://docs-media.metaslider.com/publishpress-blocks/padding-margin-134ba30741.webp)

*Padding Margin*

![Icon Margin](https://docs-media.metaslider.com/publishpress-blocks/icon-margin-d5d09589a1.webp)

*Icon Margin*

## Default settings for all your PublishPress Icon blocks [#](#4-toc-title)

You can set default options for every PublishPress Icon block added to your site. This is possible with the [PublishPress Blocks default configuration](https://publishpress.com/knowledge-base/default-blocks-config/) feature and it allows you to create a consistent look-and-feel for all your icons.

- Go to “Blocks” in your WordPress admin menu, then “PublishPress Blocks”.
- Click the“Icon” settings icon.

![](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-10-05-at-153108-18f3f10a95.webp)

- Adjust the default settings and save.

![](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-10-05-at-153144-0649dda0e2.webp)
