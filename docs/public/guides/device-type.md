# Device Type Control

The “Device Type Control” feature is part of the [Block Controls](https://publishpress.com/links/block-controls) feature in the [PublishPress Blocks](https://publishpress.com/links/blocks) plugin. This feature allows you to select what type of device this block will be visible on. You are presented with four options:

- Desktop
- Tablet
- Mobile
- Bot

The screenshot below shows an example of the Device Type Control feature. this block will only be visible on the front of the site to users on mobile devices.
