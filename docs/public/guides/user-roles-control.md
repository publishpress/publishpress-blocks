# User Roles Control

The “User Roles Control” feature is part of the [Block Controls](https://publishpress.com/links/block-controls) feature in the [PublishPress Blocks](https://publishpress.com/links/blocks) plugin. This feature allows you to control who can see a specific Gutenberg block on the frontend of your website. There are six different options available for this role:

- Show to everyone
- Hide from everyone
- Show to logged in users
- Show to logged out users
- Show to the selected user roles
- Hide from the selected user roles

![User role control](https://docs-media.metaslider.com/publishpress-blocks/user-role-control-abaef98853.webp)

If you select either “Show to the selected user roles” or “Hide from the selected user roles”, you will be able choose the specific users that will be impacted by this setting. In the screenshot below, this block will only be visible on the frontend of the site to users in the Administrator or Editor roles.

![Show to the selected user roles](https://docs-media.metaslider.com/publishpress-blocks/specific-user-roles-7d297df8fb.webp)
