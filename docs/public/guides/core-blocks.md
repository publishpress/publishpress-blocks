# Google Fonts in Core Blocks (Pro)

This feature requires the Pro version of the PublishPress Blocks plugin.

The Pro version of the [PublishPress Blocks](https://publishpress.com/links/blocks) allow you to add use Google fonts with some core Gutenberg blocks such as paragraph and heading.

You can choose between 1400 available Google fonts to apply to paragraph and heading blocks.

1. Select the paragraph or heading block
2. Go to Font settings sidebar
3. Choose a Font family and Font weight

![PublishPress Blocks - Core Blocks](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-05-18-at-142550-969462f963.webp)

- **Font family**. Choose between 1400 available Google fonts
- **Font weight + Style**. (when Font family is different to “default”)
- **Force styling**. This adds !important to CSS in frontend to avoid your font being overridden.
