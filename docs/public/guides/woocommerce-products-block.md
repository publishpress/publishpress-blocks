# Woo Products Block

Table of Contents

- [How to add a Woo Products block](#h-how-to-add-a-publishpress-woo-products-block)
- [Settings for the Woo Products block](#h-settings-for-the-publishpress-woo-products-block)

[PublishPress Blocks](https://publishpress.com/links/blocks) comes with a block to display your WooCommerce products. There are 2 layouts available for the **PublishPress Woo Products** block: the Grid and Slider views.

![](https://docs-media.metaslider.com/publishpress-blocks/latest-posts-woocommerce-recent-products-d608160f2e.webp)

## How to add a Woo Products block [#](#h-how-to-add-a-publishpress-woo-products-block)

You can insert this block by clicking the “Woo Products – PublishPress”button in the [PublishPress Blocks](https://publishpress.com/links/blocks) category.

![](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-10-05-at-181154-0e4933bdd2.webp)

The **Woo Products** block will appear in your Gutenberg editor, with settings in the right sidebar. You can see how the blocks will be displayed in the frontend in the image below:

![](https://docs-media.metaslider.com/publishpress-blocks/woo-block-160c82d334.webp)

## Settings for the Woo Products block [#](#h-settings-for-the-publishpress-woo-products-block)

On the right panel, you can adjust the settings of each layouts:

- **Products Settings**  Product Status Category
- **Layout Settings**  Columns Number of Products Order

![](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-10-05-at-181236-9b7746f22e.webp)

## Default settings for the Woo Products block [#](#h-default-settings-for-the-publishpress-woo-products-block)

You can set default options for every PublishPress Woo Products block added to your site. This is possible with the [PublishPress Blocks default configuration](https://publishpress.com/knowledge-base/default-blocks-config/) feature and it allows you to create a consistent look-and-feel for all your WooCommerce products.

- Go to **Blocks** in your WordPress admin menu, then **PublishPress Blocks**.

- Click **Woo Products** settings icon.

![](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-10-05-at-181352-006a76352e.webp)

- Adjust the default settings and save.

![](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-10-05-at-181405-f2e7772754.webp)
