If you want to show multiple images in a slider / slideshow, then the PublishPress Images Slider block is a great option. This block is available in the [PublishPress Blocks](https://publishpress.com/links/blocks) plugin. This block has advanced features including overlays, auto height, text, color and alignment options.

## How to add a PublishPress Images Slider block [#](#h-how-to-add-a-publishpress-images-slider-block)

To create a PublishPress Images Slider block, click the“Images Slider – PublishPress”button in the [PublishPress Blocks](https://publishpress.com/links/blocks) category.

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-172123-07c6ee8443.webp)

## Adding images to a PublishPress Images Slider block [#](#h-adding-images-to-a-publishpress-images-slider-block)

These next steps will help you choose the images for your block:

- After creating a **PublishPress Images Slider** block, click the blue **Add images** button.
- Upload or search for the images you want to use.
- Click on all the the images you want to add to your slider.
- Click the **Select** button.

![](https://docs-media.publishpress.com/publishpress-blocks/media-slider-1-dece813115.webp)

- You can now input the **Title** and **Text** for each image.

![](https://docs-media.publishpress.com/publishpress-blocks/title-text-slider-2f81bc18f4.webp)

You can add, rearrange and remove images using the toolbar below the **Title** and **Text** fields.:

- **Add images**: Click the large + button.
- **Remove images**: Click the large red X next to an image.
- **Rearrange images**: Click the left and right arrows on each image.

![](https://docs-media.publishpress.com/publishpress-blocks/rearrange-slider-639a396191.webp)

## Settings for the PublishPress Images Slider block [#](#h-settings-for-the-publishpress-images-slider-block)

You can edit the settings for your slider on the right sidebar:

**Image Settings**

- **Action on click**: None, Open image in lightbox, or Open custom link.
- **Full width**: Enabled or disabled.
- **Auto height**: Enabled or disabled.
- **Always show overlay**: Enabled or disabled.
- **Enable RTL**: Enabled or disabled.

**Color Settings**

- Hover Color
- Title Color
- Text Color

![](https://docs-media.publishpress.com/publishpress-blocks/slide-settings-1-12436f2906.webp)

**Text Alignment**

- **Vertical Alignment**  Top Center Bottom
- **Horizontal Alignment**  Left Center Right

![](https://docs-media.publishpress.com/publishpress-blocks/slide-settings-2-7414563c9e.webp)

## Google font support (Pro) [#](#anchor-support-pro)

This feature requires the Pro version of the PublishPress Blocks plugin.

This feature is available in the Pro version of PublishPress Blocks. You can choose between 1400 available Google fonts to customize the title and text. You can choose a different font for each element! These settings are available through “Title” and “Text” panels.

![PublishPress Blocks - Images slider](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-04-27-at-152051-ae74c2e8e9.webp)

- **Font family**. Choose between 1400 available Google fonts
- **Font weight + Style**. (when Font family is different to “default”)

## Autoplay support (Pro) [#](#anchor-support-pro)

This feature requires the Pro version of the PublishPress Blocks plugin.

To enable autoplay and change the autoplay speed, do it through the “Autoplay” panel in the sidebar. The speed is in miliseconds. As example: to set 5 seconds interval between slides, type 5000.

![PublishPress Blocks - Images slider](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-04-27-at-152234-3c7c88661e.webp)

## Change title and text tag (Pro) [#](#anchor-support-pro)

This feature requires the Pro version of the PublishPress Blocks plugin.

You can change the HTML tag for the title and text in order to display the content in a different size.

![PublishPress Blocks - Images slider](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-04-27-at-152410-bbdc3b964e.webp)

1. Go to “Title” or “Text” panel > Tag
2. Choose a different HTML tag

## Hide title (Pro) [#](#anchor-support-pro)

This feature requires the Pro version of the PublishPress Blocks plugin.

Disable the title if you want to include the title as alt attribute without displaying the title over the image. This for SEO reasons.

![PublishPress Blocks - Images slider](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-05-18-at-131046-7309336966.webp)

1. Go to “Title” panel
2. Disable “Display”

## Default settings for your PublishPress Images Slider blocks [#](#h-default-settings-for-your-publishpress-images-slider-blocks)

You can set default options for every PublishPress Images Slider block added to your site. This is possible with the [PublishPress Blocks default configuration](https://publishpress.com/knowledge-base/default-blocks-config/) feature and it allows you to create a consistent look-and-feel for all your slider / slideshows.

- Go to **Blocks** in your WordPress admin menu, then **PublishPress Blocks**.

- Click **Images Slider** settings icon.

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-172301-63e9334973.webp)

- Adjust the default settings and save.

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-172315-b684a307d2.webp)
