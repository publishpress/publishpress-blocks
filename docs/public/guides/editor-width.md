# Editor width

This feature is on [the Settings screen](https://publishpress.com/knowledge-base/configuration/) in the [PublishPress Blocks](https://publishpress.com/links/blocks) plugin. This feature can modify the width of the Gutenberg editor screen.

![](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-10-04-at-163020-34889cab2f.webp)

You can also access this setting by clicking the [PublishPress Blocks](https://publishpress.com/links/blocks) icon when you’re writing a post:

![Screen Shot 2020 12 09 At 17.40.55](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2020-12-09-at-174055-a7fcd59df9.webp)

This image shows the “Original” setting with a PublishPress [Image block](https://publishpress.com/knowledge-base/advanced-image-block/). When using “Default”, you’ll see the default width defined by the theme.

![](https://docs-media.metaslider.com/publishpress-blocks/original-8eb35fd9ce.webp)

This final image shows the same screen with the “Full width” option:

![](https://docs-media.metaslider.com/publishpress-blocks/full-width-1419b255bd.webp)
