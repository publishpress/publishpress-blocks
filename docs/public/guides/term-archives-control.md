# Term Archives Control

The “Term Archives Control” feature in the [PublishPress Blocks](https://publishpress.com/links/blocks) plugin allows you to choose on which taxonomies and terms archive pages your blocks are displayed.

You can add the following restrictions to any Gutenberg block through the Widgets and Site Editor screens:

- Hide a block in archive pages of selected taxonomies and terms
- Show a block in archive pages of selected taxonomies and terms

Here’s how to use the Term Archives Control feature:

- Go to “Appearance” then “Editor in your WordPress admin menu.
- Select a block and look for “[Block Controls](https://publishpress.com/links/block-controls)” in the right sidebar.
- Find the “Term archives” setting.
- Choose either “Show for selected terms” or “Hide for selected terms.
- Select the taxonomies you want to use.

![Term archives block control](https://docs-media.publishpress.com/publishpress-blocks/site-editor-term-archives-1-73c5f881f3.webp)

- If you want to restrict show or hide the block only on some terms, use the “Filter terms” field.
