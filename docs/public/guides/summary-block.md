# Table of Contents Block

Table of Contents

This feature requires the Pro version of the PublishPress Blocks plugin.

The Table of Contents block is available in the [PublishPress Blocks](https://publishpress.com/links/blocks) plugin. This allows you to show a Table of Contents for your posts created with Gutenberg. WordPress automatically creates this Table of Contents using the headings in your post. This blocks enables you to place that Table of Contents so your visitors can see it.

![](https://docs-media.publishpress.com/publishpress-blocks/summary-gutenberg-content-7e73f5c488.webp)

## How to create the Table of Contents block [#](#articletoc_0)

You can create a Table of Contents block by clicking the “Table of Contents – PublishPress” button in the [PublishPress Blocks](https://publishpress.com/links/blocks) category.

Before you do this, we recommend that you create at least one Heading tag in the post or page.

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-180145-af4097ab08.webp)

## How to use the Table of Contents block [#](#articletoc_0)

The Table of Contents can be aligned to the Left, Center or Right. To update it, use the Update Summary button.

On the right panel, there are some options that you can adjust:

- **Load minimized:** If you enable this feature, the Summary will be hidden by default. Users will need to click the **Summary header title** text to see the Summary.
- **Summary header title:** This is shown when the **Load minimized** option is enabled
- **Anchor color:** pick a color for the Summary links.

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-180252-05d13e2703.webp)

## Accordion support (Pro) [#](#anchor-support-pro)

This feature is available in the Pro version of PublishPress Blocks. [The headings of the accordions](https://publishpress.com/knowledge-base/advanced-accordion-block/#table-of-contents-support-pro) can be included in the Table of Contents block.

## Default settings for all your Table of Contents blocks [#](#h-default-settings-for-all-your-publishpress-table-of-contents-blocks)

You can set default options for every PublishPress Table of Contents block added to your site. This is possible with the [PublishPress Blocks default configuration](https://publishpress.com/knowledge-base/default-blocks-config/) feature and it allows you to create a consistent look-and-feel for all your table of contents.

- Go to **Blocks** in your WordPress admin menu, then **PublishPress Blocks**.

- Click **Table of Contents** settings icon.

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-180435-bdafb86de3.webp)

- Adjust the default settings and save.

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-180449-5b4a1e0994.webp)
