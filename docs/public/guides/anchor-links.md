# Anchor Links for Blocks

It is possible to create anchor links for blocks. This allows you to create direct links to blocks, rather than to the top of a page. They allow visitors to click a link and instant moved up or down a long page. [Learn more about anchors.](https://wordpress.org/support/article/page-jumps/)

- When editing a block, look for the “Advanced” tab in the right sidebar.
- Under the “Advanced” tab, look for the “HTML anchor” box.
- Enter the name of your anchor.

![Html Anchor](https://docs-media.metaslider.com/publishpress-blocks/html-anchor-8adadb9789.webp)

*Html Anchor*

This feature is available for all [PublishPress blocks](https://publishpress.com/links/blocks), except for these:

- Icons
- Columns
- [Info Box](https://publishpress.com/links/info-box)
- Content Display
- Testimonial
