The PublishPress List block is available in the [PublishPress Blocks](https://publishpress.com/links/blocks) plugin. This block is based on the default List block in Gutenberg. This improved version of the block has tons of extra features including advanced styling such as custom icons, text size, margin, padding and more.

## How to create the PublishPress List block [#](#articletoc_0)

You can create an PublishPress List block by clicking the “List – PublishPress” button in the [PublishPress Blocks](https://publishpress.com/links/blocks) category:

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-155456-ca5333200d.webp)

## Text settings in the PublishPress List block [#](#articletoc_0)

After creating the PublishPress List block, you can adjust the settings from the right sidebar. You can change the text size:

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-155843-09b2ea51bd.webp)

## Icon settings in the List block [#](#articletoc_0)

After creating the PublishPress List block, you can adjust the settings from the right sidebar. You can change the icon and it’s settings:

- List icon
- Icon size
- Line height
- Margin
- Padding

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-155940-0a01e831cc.webp)

## Reorder items [#](#reorder-items)

You can reorder your list items thanks to the new List item block. Use the up/down arrows to change the order of the list items.

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2023-02-09-at-113822-510b8a3260.webp)

## Text color support (Pro) [#](#anchor-support-pro)

This feature requires the Pro version of the PublishPress Blocks plugin.

This feature is available in the Pro version of PublishPress Blocks. You can add a custom color to the whole list.

![PublishPress Blocks - Advanced List](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-03-30-at-122008-ac2878f764.webp)

1. Go to Colors panel
2. Choose a Text color

## Default settings for all your PublishPress List blocks [#](#5-toc-title)

You can set default options for every PublishPress Lis**t** block added to your site. This is possible with the [PublishPress Blocks default configuration](https://publishpress.com/knowledge-base/default-blocks-config/) feature and it allows you to create a consistent look-and-feel for all your lists.

- Go to **Blocks** in your WordPress admin menu, then **PublishPress Blocks**.

- Click **List** settings icon.

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-160034-0b19756191.webp)

- Adjust the default settings and save

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-160103-ff2b55b601.webp)
