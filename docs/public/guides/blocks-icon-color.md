# Blocks icon color

This feature is on [the Settings screen](https://publishpress.com/knowledge-base/configuration/) in [PublishPress Blocks](https://publishpress.com/links/blocks). This feature can change the color of the [PublishPress Blocks](https://publishpress.com/links/blocks) icons when you are creating content.

This image shows the default display of PublishPress Blocks icons:

![](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-10-04-at-162713-3441aea49c.webp)

In the Settings screen, I have changed the color to #de528a

![](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-10-04-at-162834-06fa71f80f.webp)

This next image shows how the blocks from PublishPress Blocks will now appear:
