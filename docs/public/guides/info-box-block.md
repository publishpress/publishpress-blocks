The **PublishPress Info Box**block is a great way to show important information. This is available in the [PublishPress Blocks](https://publishpress.com/links/blocks) plugin. You can have large, colorful icon displayed next to a large title and some text. This block allows you to use Google’s Material Design icons.

## How to add a PublishPress Info Box block [#](#articletoc_0)

Click the“Info Box – PublishPress”blockbutton in the [PublishPress Blocks](https://publishpress.com/links/blocks) category:

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-172918-01785187e5.webp)

This next image shows how the PublishPress Info Box block will appear inside your WordPress editor:

![](https://docs-media.publishpress.com/publishpress-blocks/info-block-91f075c1e8.webp)

## Container settings for the PublishPress Info Box block [#](#1-toc-title)

These settings allow you to customize the background and border colors for your box, plus the border width and padding:

- Background Color
- Border Color
- Border Width (px)
- Border Radius (px)
- Padding (px, em, vh or %)

![](https://docs-media.publishpress.com/publishpress-blocks/container-settings-6e939e667d.webp)

## Icon settings for the PublishPress Info Box block [#](#2-toc-title)

These settings allow you to customize the large icon inside your block. There are dozens of icons to choose from. The block uses Google’s Material Design icons.

![](https://docs-media.publishpress.com/publishpress-blocks/icon-choice-c7f7157d28.webp)

These are the available settings for the icons:

- Icon Color
- Icon Size (px)
- Background Color
- Border Color
- Border Width (px)
- Border Radius (px)
- Padding (px, em, vh or %)
- Margin (px, em, vh or %)

![](https://docs-media.publishpress.com/publishpress-blocks/icon-settings-1-2fb61fdf4f.webp)

![](https://docs-media.publishpress.com/publishpress-blocks/icon-settings-2-2a7f40b718.webp)

- Padding (px, em, vh or %)
- Margin (px, em, vh or %)

## Default settings for the PublishPress Info Box block [#](#5-toc-title)

You can set default options for every PublishPress Info Box block added to your site. This is possible with the [PublishPress Blocks default configuration](https://publishpress.com/knowledge-base/default-blocks-config/) feature and it allows you to create a consistent look-and-feel for all your info boxes.

- Go to **Blocks** in your WordPress admin menu, then **PublishPress Blocks**.

- Click **Info Box** settings icon.

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-172708-4ea1e84218.webp)

- Adjust the default settings and save.

![](https://docs-media.publishpress.com/publishpress-blocks/screen-shot-2022-10-05-at-172722-1a47aee4db.webp)
