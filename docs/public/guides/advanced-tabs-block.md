The **PublishPress Tabs** block is available in the PublishPress Block plugin. The tabs are ideal for when you need display a lot of content in a small area. The tabs are mobile-friendly, can be horizontal or vertical, and can be customized with your colors and design.

![](https://docs-media.metaslider.com/publishpress-blocks/gutenberg-tabs-block-518d4575ce.webp)

## How to create a Tabs block [#](#h-how-to-create-an-publishpress-tabs-block)

To insert an ****PublishPress** Tabs** block, click the “Tabs – PublishPress” button in the [PublishPress Blocks](https://publishpress.com/links/blocks) category.

![](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-10-05-at-164944-5ca53a0ae6.webp)

## How to add and remove tabs [#](#h-how-to-add-and-remove-tabs)

- You can add tabs using the **+** icon.
- You can remove tabs using the yellow X icon.

![](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-03-10-at-132749-d5b41448cf.webp)

## Tab settings for the Tabs block [#](#h-tab-settings-for-the-publishpress-tabs-block)

These settings allow you adjust the tab direction and also which tab people will see when they open the page:

- **Tabs style**  Desktop, Tablet or Mobile Horizontal or Vertical
- **Tabs settings**  Initial Open Tab: Which tab will be open when users load the page.

![](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-10-05-at-165042-1fc615ed54.webp)

## Tab colors for the Tabs block [#](#h-tab-colors-for-the-publishpress-tabs-block)

These settings allow you to control the main colors for your tabs:

**Tab Colors**

- Background Color
- Text Color
- Active Tab Background Color
- Active Tab Text Color

![](https://docs-media.metaslider.com/publishpress-blocks/tab-settings-1-0c25d00abd.webp)

## Body and border settings for the Tabs block [#](#h-body-and-border-settings-for-the-publishpress-tabs-block)

These settings allow you to control the body and border of your tabs:

- **Body Colors**  Background Color Text Color
- **Border Settings**  Border Style: None, Solid, Dashed or Dotted Border Color Border Width Border Radius

![](https://docs-media.metaslider.com/publishpress-blocks/tab-settings1-1-a7704a1a5c.webp)

## Custom size, Google font and spacing support for tabs (Pro) [#](#font-size-pro)

This feature is available in the Pro version of [PublishPress Blocks](https://publishpress.com/links/blocks). You can hange the font size for tabs and choose between 1400 available Google fonts. You can also transform the text: capitalize, uppercase or lowercase. In addition you can change the spacing between tabs and content. These settings are available in the Pro Tab Settings panel.

![](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2023-02-14-at-90521-ef7a04c4da.webp)



The negative spacing values makes more sense when using the “Folder” theme preset. See more details below.

## Theme presets (Pro) [#](#anchor-support-pro)

This feature is available in the Pro version of PublishPress Blocks. Choose one of the 4 theme presets to change the design of your tabs with one click. Please note despite choosing a theme preset you can still customize colors and design as usual. This setting is available in Theme settings panel.

![](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2023-02-14-at-91335-acfb36a6e8.webp)

- **Preset.** Choose between default, square, folder and cartoon.

## Anchor support (Pro) [#](#anchor-support-pro)

This feature is available in the Pro version of PublishPress Blocks. You can add custom anchors to the tabs, and open a tab through a URL.

![PublishPress Blocks - Advanced Tabs, anchor support](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-03-10-at-131825-e860e4f862.webp)

1. Add the anchor by clicking in the tab and typing in the field above
2. In frontend, open the post/page link by attaching the custom anchor. As example: `yoursite.com/the-page/#custom-anchor`

Important: the anchor must be a unique id.

## Reorder tabs (Pro) [#](#reorder-tabs-pro)

This feature is available in the Pro version of PublishPress Blocks. To reorder tabs, use the arrows to move the selected tab to the left or right:

![PublishPress Blocks - Advanced Tabs, reorder vertical tabs](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-03-10-at-132106-fcb4922035.webp)

## Default settings for all your Tabs blocks [#](#h-default-settings-for-all-your-publishpress-tabs-blocks)

You can set default options for every PublishPress Tabs block added to your site. This is possible with the [PublishPress Blocks default configuration](https://publishpress.com/knowledge-base/default-blocks-config/) feature and it allows you to create a consistent look-and-feel for all your tabs.

- Go to **Blocks** in your WordPress admin menu, then **PublishPress Blocks**.

- Click **Tabs** settings icon.

![](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-10-05-at-165152-86294ef1f0.webp)

- Adjust the default settings and save

![](https://docs-media.metaslider.com/publishpress-blocks/screen-shot-2022-10-05-at-165208-6b254e151c.webp)
